review design **Eternal GM: Complete Product & Technical Design Document**   **Version 1.0 – May 2026**   **Word count: ~3,850** (well under 5,000 limit) ### 1. Executive Summary Eternal GM is a premium SaaS platform that transforms the proven text-only LLM campaign system (God Mode, persistent multi-year campaigns, custom D&D-style classes, faction/corruption tracking, any-setting flexibility) into a **real-time 2D animated RPG experience**.   One user sentence instantly generates an entire world, characters, mechanics, and animated sprites. New NPCs emerge dynamically with reactions (e.g., “guard notices the kill”) and pop into the live scene with full animations.   **Core Value**: The narrative depth, mechanical rigor, and player agency of your Ramsay/Pax Julia/Nocturne/Sariel campaigns — now with beautiful pixel-art/2D sprites, 60 FPS movement, and seamless visuals — without sacrificing the LLM’s God Mode power.   **Target Users**: TTRPG fans, solo storytellers, writers, and indie devs who want Wrtn-scale storytelling with visual polish.   **Monetization Potential**: $29–$79/mo tiers → $3M+ ARR at 5,000 users (inspired by Wrtn’s $8M+/mo trajectory).   **Differentiation**: Beats AI Dungeon (polish + mechanics), AI Roguelite (narrative depth + persistence), and Friends & Fables (real-time sprite animation + one-sentence world gen). ### 2. Product Vision & Key Features **Vision**: “One sentence → living animated world you control forever.”   The LLM remains the GM; visuals are a reactive layer. Pure-text mode always available for purists. **Core Features**   - **Instant World Creation**: One sentence → LLM parses bible + mechanics + 4–8 starter characters → generates consistent sprite sheets + animations + tile map.   - **Dynamic Emergent NPCs**: LLM decides a new character appears → async sprite/animation generation (<15s) → sprite fades in and joins the scene with immediate idle/walk/reaction animations.   - **God Mode Panel**: Prefix any message with “God Mode:” for instant overrides (stats, lore, sprites, mechanics) that persist forever.   - **Persistent Campaign State**: Full character sheets (custom classes to lvl 30), faction trackers, corruption meters, timelines, branching histories.   - **Real-Time 2D Canvas**: PixiJS-powered scene with player-controlled camera, pathfinding movement, combat animations, particle effects.   - **Mechanics Engine**: Rules-agnostic JSON schemas for any system (D&D 5e, custom Dreadblade Shadow, Imperator, Psionicist, etc.). Simulated dice with reproducible JSON output.   - **Multiplayer (Pro+)**: Shared sessions with turn queuing and presence.   - **Export/Share**: Full campaign JSON + sprite assets + Markdown logs.   - **Style Switching**: Pixel-art default, but toggle dark fantasy, sci-fi, modern, etc. per campaign. **Differentiators vs Competitors**   - vs AI Dungeon: Deeper mechanics + real-time animated sprites.   - vs AI Roguelite: Persistent God Mode campaigns + any genre.   - vs Text LLM GMs: Beautiful 2D visuals without losing narrative quality. ### 3. User Experience & UI Design **Overall Theme**: Dark modern-fantasy (deep blacks, glowing purple/gold accents, elegant serif headings). Responsive desktop-first + mobile PWA. **Main Screens**   1. **Campaign Hub (Home)**      - Left sidebar: My Campaigns | Browse Templates | Community Worlds | Create New.      - Central grid: Campaign cards with thumbnail sprite, last session date, key meters (corruption %, faction strength).      - Quick prompt bar: “A half-Bolton assassin rescues the Starks at the Red Wedding” → one-click world gen.   2. **Live Session Screen (Core Play Area)**      - **70% Canvas (PixiJS)**: Real-time 2D animated scene (top-down or isometric). Player sprite controllable via click-to-move or WASD. NPCs animate independently.      - **Right Sidebar (collapsible)**:        - Character Sheet (levels, stats, custom class progression, inventory).        - Status Dashboard (HP, resources, corruption, faction overview).        - God Mode toggle + quick dice roller.      - **Bottom Bar**: Text input + voice + “God Mode:” hotkey. Streaming narration appears above canvas.      - **Top Bar**: Scene illustration toggle, minimap, session timer.   3. **God Mode Overlay**: Full-screen admin panel that freezes time. Direct JSON edits to state/sprites; “Apply & Resume” button.   **Visual Inspirations** (matching previous renders): Dark fantasy character UI, pixel-art inventory sheets, ornate frames, modern SaaS dashboards with glowing AI accents.   **Mobile**: Vertical stack – narrative + canvas first, swipe for sheets. Floating God Mode button. ### 4. Technical Architecture **High-Level**: Hybrid event-driven microservices. Frontend renders visuals in real time; backend orchestrates LLM + sprite generation asynchronously. **Frontend**   - Next.js 15 (App Router) + TypeScript + Tailwind + shadcn/ui.   - **2D Engine**: PixiJS v8 (WebGL) or Phaser 4 for sprite animation, physics, and pathfinding (A* on tile grid).   - State: Zustand + TanStack Query for campaign data; local canvas state synced to backend every 2–5s.   **Backend**   - FastAPI (Python) or NestJS for orchestration.   - **LLM Layer**: LangGraph multi-agent system:     - Narrative Agent (streaming prose).     - Mechanics Agent (JSON state deltas + dice).     - Visual Agent (structured JSON for sprite commands).   - Models: Grok-4 / Claude 3.7 / GPT-4o + fallback to local (Ollama) for low-latency narration.   **Database**   - PostgreSQL + pgvector: Campaigns, character sheets, history (vector embeddings for RAG recall).   - Redis: Active session cache, sprite metadata, generation queue.   - S3: Sprite sheets and animation frames.   **Visual Generation Pipeline (Real-Time Focus)**   1. **One-Sentence Trigger** → LLM parses → outputs structured JSON:      ```json    {      "world_bible": "...",      "characters": [{"name": "Ramsay", "description": "...", "style": "pixel-art dark-fantasy"}],      "initial_npcs": [...],      "mechanics_schema": {...}    }    ```   2. **Sprite Generation (async, <15s)**:      - Ludo.ai / Scenario / Leonardo.ai + Flux.1 Kontext for base reference images.      - Consistency: Campaign-specific LoRA (fine-tuned once on 10–20 frames) + IP-Adapter + ControlNet (OpenPose for poses).      - Output: Transparent 128×128 PNG sprite sheets (idle, walk-8dir, attack, reaction, death).   3. **Animation**:      - Text-to-sprite tools (Ludo.ai AutoSprite, voidless.dev, or Kling AI short clips converted to sprite sheets).      - 8–12 frame loops per state.   4. **Dynamic Pop-Ups**: LLM triggers “emergent_npc” event → background queue → new AnimatedSprite instantiated on canvas with fade-in + immediate idle animation.   5. **Real-Time Loop**:      - LLM outputs JSON every 1–3s: {action: "move", target: "guard", animation: "alert"}.      - PixiJS updates position, plays animation, triggers particles.      - Pre-cached base sprites for instant feel; full-res upgrades in background. **Performance Optimizations**   - Sprite pooling & caching.   - Tiered generation (fast low-res during combat, full-res for cutscenes).   - Edge hosting (Vercel + Cloudflare) for <200ms latency.   - Cost: $0.02–0.15 per new sprite/animation set. **Security & Compliance**   - Row-level security (users see only their campaigns).   - Encrypted state.   - Moderation layer for sensitive content. ### 5. LLM & Mechanics Integration - **System Prompt Template**: Full campaign bible + last 20 turns + current sprite metadata + God Mode flags.   - **Consistency Guardrails**: Post-processing validates state (stats, locations, sprites).   - **Mechanics**: Fully custom JSON schemas (e.g., Dreadful Dice scaling, corruption %). Simulated dice return reproducible JSON.   - **Parallel Agents**: Narrative streams to UI while mechanics/visuals update in background.   ### 6. Monetization & Business - **Tiers**:     - Free: 3 campaigns, text-only, limited generations.     - Pro ($29/mo): Unlimited + real-time sprites + God Mode.     - Legend ($79/mo): Multiplayer, custom LoRAs, priority models, asset export.   - **Revenue Model**: Subscription + credit packs for heavy image gen.   - **Market Validation**: Mirrors Wrtn’s $8M+/mo success in interactive storytelling; adds visuals for higher retention. ### 7. Implementation Roadmap (12 Months) **Phase 1 (Months 1–3)**: MVP – Text + basic PixiJS sprites (static first). One-sentence world gen. God Mode.   **Phase 2 (Months 4–6)**: Full animated sprites + dynamic pop-ups. Ludo.ai integration.   **Phase 3 (Months 7–9)**: Multiplayer, style switching, export.   **Phase 4 (Months 10–12)**: Mobile apps, community marketplace, analytics.   **Tech Debt & Risks Mitigated**: Sprite consistency via LoRAs; generation speed via queuing; cost via model tiering. ### Next Steps 1.
