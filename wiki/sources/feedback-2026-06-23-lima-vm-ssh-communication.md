## Summary

The 16 self-hosted Linux runners (`org-runner-1..16`) run inside a Lima/QEMU VM called `colima` that lives on the Ubuntu host `jeff-ubuntu`. To run any command inside the Lima guest from the Mac, you must chain two SSH connections: `ssh jeff-ubuntu "ssh -p 40257 -i ~/.lima/_config/user 127.0.0.1 ..."`. Lima normally picks a random SSH port on each restart, so any probe script must pin the port via `ssh.localPort: 40257` in `lima.yaml`.

## Key Claims

- Lima VM is reachable only via a two-stage SSH hop from Mac — Mac cannot directly reach the guest because the QEMU network is internal to jeff-ubuntu.
- Port 40257 must be pinned in lima.yaml or Lima will assign a random port on each restart, breaking watchdog and health-monitor probes.
- The SSH key `~/.lima/_config/user` is auto-generated by Lima on first boot — using any other key fails silently.
- Verification probe is a single command: `ssh jeff-ubuntu "ssh -p 40257 ... 127.0.0.1 echo LIVE"`.

## Key Quotes

> "Lima contains 16 self-hosted Linux runners, and three recent incidents (June 18-23 hang, false dead diagnoses, broken probes) all trace to agents not knowing this pattern."

> "The QEMU network is internal to jeff-ubuntu. Only jeff-ubuntu can reach the Lima guest's loopback port forward."
