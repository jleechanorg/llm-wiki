## Summary

Fixed PreToolUse hook exit-code behavior so warn-only conflicts show a TUI banner and no-conflict cases stay silent. Before the fix, both paths produced no visible feedback to the user.

## Fix Details

- No-conflict path → call `_silent_approve()` (emits `{"decision":"approve"}` only, no `systemMessage`)
- Warn-only conflict → emit `_emit("allow", reason)` then `sys.exit(1)`; first stderr line becomes TUI notification
- Block → emit `_emit("deny", reason)` then `sys.exit(2)` (or return, as the function exits)
