# Prime Radiant, Inc.

**Role:** Author and maintainer of `superpowers-cloud-build` plugin (verified v0.8.1, 2026-07-20).

**License:** MIT (per `~/superpowers-cloud-build-main/LICENSE`).

**Distribution model:** Invite-only. Plugin archive is served from `pub-347cd78fe2db440ab5f46aa1c1307d59.r2.dev` (Cloudflare R2). Enrollment codes are one-shot, single-use, expire in 24-48h.

**Notable:** Not affiliated with Anthropic (Claude Code / Superpowers) or OpenAI (Codex). Prime Radiant is the third leg of the Superpowers ecosystem — provides the remote-execution backend that plugs into both Claude Code and Codex harnesses.

**Source of confusion:** Easy to mistake for an Anthropic-published plugin because it's surfaced through `codex plugin marketplace` and `/plugin marketplace`. The `.claude-plugin/plugin.json` `author` field is the authoritative source.
