## jeff-ubuntu

The Ubuntu Linux host machine that runs the Lima/QEMU VM `colima` which hosts the 16 self-hosted Linux GitHub Actions runners.

### Network

- Reachable from the Mac via SSH alias `jeff-ubuntu` (configured in `~/.ssh/config`)
- Runs the Lima QEMU process for the `colima` VM
- Exposes Lima's SSH port on `127.0.0.1:40257` (loopback only — not reachable from outside the host)

### Key paths

- Lima home: `~/.lima/colima/`
- Lima config: `~/.lima/colima/lima.yaml` (must contain `ssh.localPort: 40257`)
- Lima SSH key: `~/.lima/_config/user`
- Docker socket (host-side forward): `~/.lima/colima/sock/docker.sock`
- Runtime mirror (stable script install dir): `~/.local/share/worldarchitect-colima-runners/`
- Work log dir: `~/.worldarchitect-runner/work/`
- Cron logs: `monitor.log`, `cleanup.log`, `hard-cleanup.log`, `lima-watchdog.log`

### Installed binary locations

- `~/.local/bin/limactl` — Lima CLI (built from Go source by install.sh)
- `/usr/bin/gh` — GitHub CLI (system package)
- `/usr/lib/go-1.23/bin/go` — Go toolchain (Ubuntu 24.04 package)

### SSH key for Lima guests

`~/.lima/_config/user` is auto-generated by Lima on first boot. It is the only SSH key the Lima guest's sshd will accept. Using `~/.ssh/id_rsa` or any other key from the host will be silently rejected.

### Why this host

This is the only Linux host with persistent network/storage for the 16-runner fleet. The Mac could not host 16 simultaneous Linux runners (architecture mismatch, RAM/CPU constraints), so the Linux fleet lives here in a VM that lets us scale to 16 containers within a single QEMU guest.
