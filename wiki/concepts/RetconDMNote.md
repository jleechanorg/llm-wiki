# Retcon DM Note

The [[CampaignSummaryPrompt]]'s mechanism for recording retcons — events the DM retroactively changed — as explicit "DM Note" entries in the chronological summary rather than silently rewriting the timeline. [[ChatGPT]]'s review called the base requirement well-defined but flagged a gap: **formatting multiple retcons within the same session**, suggesting a numbered form such as "DM Note Retcon (Session 3): ...".

This preserves canon integrity the same way this wiki's own log discipline does: the record shows both what originally happened and what was later overridden, instead of presenting a retconned timeline as if it had always been true. Related ordering question: [[OffScreenEventRevelation]].
