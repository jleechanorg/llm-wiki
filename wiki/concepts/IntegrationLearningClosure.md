## Summary

Canonical `/integrate` includes `/learn` automatically. Verify integration's branch outcome separately from persistence in each required learning store; a successful integration exit code proves only the integration layer.

## Practice

Preserve dated source provenance, persist the required stores, and verify their readback. A user retirement decision can remove obsolete follow-up scope while preserving historical evidence; it does not authorize deleting a distinct active system. Evidence publication checks should compare raw HTTPS bytes before treating terminal/CLI formatting transformations as corruption.
