# Dynamic Situational Modifiers

Mechanic observed in the [[Voyage]] engine ([[2026-08-04-bg3-voyage-campaign-summary]]): the system mathematically converts the current narrative state into explicit, named bonuses and penalties on checks.

Observed examples: `Distracted Enemy: +6`, `Elite Drow Support: +10`, `Shadow Stalker Reinforcements: +6`, `Recent Success: +13`, `Successful Preparations: +13`, `High-stakes Combat: -7`.

Two notable properties:
1. **Legibility** — each modifier is named and shown, so the player can audit why a check landed where it did (contrast with [[Worldsmith]]'s opacity, the player's main complaint about the same platform).
2. **State-consequence coupling** — the engine also enforces negatives from player-created conditions (ink-cloud obscurement causing allied friendly fire; psychic static garbling a telepathic kill command), i.e. modifiers flow from world state, not just player favor. Pairs with [[TieredSuccessOutcomes]].
