# Clean State Campaign Reset

LLM-DM campaign-management pattern: ask the DM to read a prior campaign chat for characterization context ("bane - main"), then explicitly start a **new** campaign with the same characters and factions but a clean world state. Continuity of cast, reset of state.

Observed in the [[ShadowOverTheGate]] genesis with [[Gemini]] as DM. Contrast with [[CampaignContextMigration]] (full state carried into a new chat to continue the SAME campaign) and [[CleanSlateCampaignRestart]]/[[FactionWebRestart]] (sibling restart variants elsewhere in the arc). The chat index's arc structure — mortal → v1m → v2m → v3m → godhood — shows this reset pattern applied repeatedly as versioned campaign iterations.
