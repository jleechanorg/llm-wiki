# Verification Gap

**One-sentence:** As of April 2026, AI-written code is 27.6% of merged PRs (Greptile 1M+ PR dataset), but only 48% of devs verify it before commit (Sonar 2026 State of Code, n=1,100) — generation is compounding at 28× over 14 months while verification stays flat.

## The asymmetry that defines the problem

Generation is doubling. Verification is constant. The wedge is the gap.

This is the same pattern as Moore's law generation vs verification in silicon: design complexity grew exponentially while formal verification stayed roughly flat, and the entire EDA industry was built to fill that gap. The agent era is producing the same shape of opportunity.

## Sonar's answer: Agent Centric Development Cycle (Guide → Verify → Solve)

1. **Guide** — pre-generation: the agent's plan, scope, and approach are explicit and reviewable
2. **Verify** — pre-merge: deterministic checks, not vibes-based review
3. **Solve** — only what passed verification ships

Sonar acquired Gitar (2026) specifically to extend automated review to AI-generated code. This is one industry attempt to productize the gap.

## What "good" looks like (industry references at AIEWF 2026)

- Anthropic Labs: evidence-driven review, scripts that check scripts, "agents that ask permission at the right moments"
- WorkOS Project Horizon: harness-level verification (not per-PR) that is durable across model versions
- Greptile: AI reviewing AI, with a feedback loop on false-positive rate

## What I'm shipping (Jeffrey's stack)
